# Спортивный IPTV-плейлист

Отдельный список: [sportsRU.m3u](sportsRU.m3u). Прямая ссылка для IPTV-плеера:

https://raw.githubusercontent.com/gwz-tools/daily-index/main/sportsRU.m3u

## Как формируется

Ежедневный workflow генерирует его из существующего `playlistRU.m3u`, не добавляя новые чужие API и ключи. Первыми идут хоккей/КХЛ, затем футбол/Матч!, затем остальной спорт.

В названиях групп **«проверено»** означает, что поток пришёл из динамической части, прошедшей последнюю проверку видео в `refresh.py`. **«резерв без свежей проверки»** означает ссылку из вручную закреплённого `fixed_prefix.m3u`: её фактическая работоспособность неизвестна и может меняться.

Если один адрес требует разные `User-Agent` или `Referer`, варианты сохраняются раздельно. Потоки с признаками персональных ключей, токенов и приватных адресов не включаются.

Важно: наличие канала или ссылка на него не подтверждает право на ретрансляцию. Используйте только источники, доступные вам на законных основаниях.

## AM Vision IPTV

В APK 0.30.0 обнаружены адреса API каталога и заголовок `X-Api-Key`. Возможность получать данные без авторизации и права на публичное распространение не подтверждены. Поэтому **AM Vision не добавлен как источник**. При наличии документированного разрешённого API его можно интегрировать отдельно без размещения ключа в публичном GitHub.
